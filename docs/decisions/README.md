# Decisions worth remembering

Write a short record when a choice has meaningful alternatives or would be
expensive to rediscover. Tiny edits do not need a committee meeting.

Name records `001-short-title.md`, then `002-...`. Start with:

- Date and status: proposed / accepted / superseded
- Context: what made a choice necessary?
- Decision: what did we choose?
- Alternatives: what else did we consider?
- Tradeoff: what do we gain and give up?
- Revisit when: what evidence would change our mind?

When a decision changes, link the old and new records. Keep the reason visible.
