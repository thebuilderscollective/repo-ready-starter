# Shipped changes

Write for people using the product. Say what they can now do and what changed.
Git records commits; this file tells readers which changes matter to them.

## Unreleased
- Documentation starter only. No application release yet.

When shipping, replace this with a dated or versioned entry, for example:

## [Version] - [Date]
### Added
- [A new user capability]
### Fixed
- [A problem users no longer encounter]

This is a format example, not a record of shipped features.
